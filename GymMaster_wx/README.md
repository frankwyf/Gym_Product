[中文](#中文) | [日本語](#日本語) | [English](#english)

## 中文

这是健身房系统的微信小程序客户端。为适配公开仓库，已将项目 `appid` 替换为示例值，并删除私有开发配置文件。

当前已接入基础多语言框架（英文/中文/日文），并在 `mine` 页面提供语言切换示例（`home` 与 `mine` 核心文案已接入，tabBar 文案随语言动态切换）。

### 使用方式

1. 使用微信开发者工具打开本目录。
2. 将 `project.config.json` 中的 `appid` 替换成你自己的小程序 AppID。
3. 根据后端地址修改全局请求配置。

### 当前状态

- 可作为代码展示与二次开发基础。
- 由于本机未配置微信开发者工具，当前未做运行验证。

## 日本語

これは WeChat ミニプログラムのクライアントです。公開用に `appid` はサンプル値へ置き換えられ、個人用設定ファイルは削除されています。

## English

This is the WeChat mini-program client. The app id was replaced with a sample value and private local configuration was removed for open-source readiness.

The mini-program now includes a baseline i18n setup (English/Chinese/Japanese), with language switching on the mine page and dynamic tab bar label localization.

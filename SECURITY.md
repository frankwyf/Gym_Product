# Security Policy

## Supported Versions

The `master` branch is considered the actively maintained branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

1. Contact maintainers privately.
2. Provide reproduction steps and impact details.
3. Allow reasonable time for triage and patching before public disclosure.

## Response Expectations

- Initial triage acknowledgment: within 7 days.
- Fix timeline depends on severity and complexity.

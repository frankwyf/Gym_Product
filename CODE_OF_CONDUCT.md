# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and inclusive.
- Giving and accepting constructive feedback.
- Focusing on what is best for the community.

Examples of unacceptable behavior include:

- Harassment, insults, or discriminatory language.
- Personal attacks, trolling, or deliberate intimidation.
- Publishing private information without permission.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

## Reporting

Please report unacceptable behavior through repository issues with the label `conduct`, or contact maintainers directly.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1.

# Support

## How to Get Help

- Open a GitHub issue with clear reproduction steps.
- Include environment details (OS, JDK, Node, Maven, DB/Redis status).
- Attach relevant logs and screenshots.

## Issue Types

- `bug`: Runtime or functional defect.
- `ci`: CI/CD pipeline problem.
- `docs`: Documentation issue.
- `question`: Usage questions.

## Before Opening an Issue

- Search existing issues first.
- Verify with latest `master`.
- Run local checks with `scripts/verify-all.ps1`.
